# Start here — publish this portfolio

1. Sign in to GitHub and open https://github.com/new.
2. Repository name: `soc-analyst-portfolio`. Select **Public**. Do not initialize a README (one is provided).
3. Extract the ZIP. Upload **the contents of the `soc-analyst-portfolio` folder**, not the outer folder or ZIP, using **Add file → Upload files**. For a large screenshot collection, GitHub Desktop or Git is more reliable than browser upload.
4. Commit with message `Publish four SOC investigation case studies`.
5. Verify the root README renders, each of the four project links opens, and evidence screenshots load.
6. Review screenshots for personally identifying details and remove anything you do not want public. Never publish credentials, tokens, or actual malware.
7. Add your real GitHub profile/repository URL to your resume and README. Pin the repository on your GitHub profile.
8. Add the GitHub link to LinkedIn Featured and your job applications.
